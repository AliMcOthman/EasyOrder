\# EasyOrder 🍔



EasyOrder ist eine einfache Food-Ordering-Webanwendung.



Mit der Anwendung können Benutzer Produkte anzeigen, suchen und Bestellungen erstellen. Außerdem gibt es einen geschützten Admin-Bereich zur Verwaltung von Bestellungen und Kontakt-Nachrichten.



\## Technologien



\* HTML5

\* CSS3

\* JavaScript

\* jQuery

\* AJAX

\* JSON

\* PHP

\* MySQL



\## Funktionen



\* Übersichtliche Startseite

\* Dynamische Produktanzeige

\* AJAX-basierte Produktsuche

\* Kategorien und Food Menu

\* Bestellformular

\* Automatische Berechnung des Gesamtpreises

\* Kontaktformular

\* Speicherung der Daten in MySQL

\* Admin Login

\* Verwaltung von Bestellungen

\* Änderung des Bestellstatus

\* Löschen von Bestellungen

\* Verwaltung von Contact Messages

\* JavaScript- und Server-seitige Validierung



\## Datenbank



Das Projekt verwendet eine MySQL-Datenbank.



Wichtige Tabellen:



\* `produkte`

\* `bestellungen`

\* `contact\_messages`

\* `users`



\## Datenfluss



Der grundlegende Datenfluss ist:



\*\*Browser → JavaScript → AJAX → PHP → MySQL → JSON → Browser\*\*



Dadurch können Daten verarbeitet werden, ohne die komplette Webseite neu zu laden.



\## Projekt starten



Das Projekt kann lokal mit \*\*XAMPP\*\* gestartet werden.



1\. Apache und MySQL in XAMPP starten.

2\. Die Projektdateien in `htdocs` speichern.

3\. Die Datenbank in phpMyAdmin einrichten.

4\. Die Webseite über den Browser öffnen.



Beispiel:



`http://localhost/EasyOrder/`
